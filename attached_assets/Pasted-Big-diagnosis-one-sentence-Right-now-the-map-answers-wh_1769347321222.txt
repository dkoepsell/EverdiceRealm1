What follows is a Hex Metadata v2 schema whose sole job is to give the map narrative authority without bloating mechanics.

Think of this as adding semantic weight to each hex, not systems.

Hex Metadata v2 (Narrative-Driven, UI-Light)
Design constraints (based on your UI)

Must work with hover + click (no modal overload)

Must visually layer onto your existing hex grid

Must explain why a hex matters right now

Must support non-combat storytelling

Must mutate over time

Core Hex Metadata v2
export interface HexMetaV2 {
  id: string;

  terrain: "Chamber" | "Corridor" | "Portal" | "Wall" | "Open";

  // 1. Narrative Promise (what kind of story this hex invites)
  narrativeTone: NarrativeTone;

  // 2. Why this hex matters right now
  currentState: HexState;

  // 3. What interacting with this hex tends to do
  affordances: HexAffordances;

  // 4. Pressure the hex exerts over time
  tension: number; // 0–100

  // 5. How the hex reacts to failure, delay, or noise
  escalation?: HexEscalation;

  // 6. What the player can learn here
  knowledgeHooks?: KnowledgeHook[];

  // 7. Visual hints for UI
  uiHints?: UIHints;
}

1. Narrative Tone (the promise)

This is the single most important addition.

export type NarrativeTone =
  | "Whispering"
  | "Sacred"
  | "Watched"
  | "Unstable"
  | "Forgotten"
  | "Hostile"
  | "Benevolent"
  | "Sealed";


Rules:

One tone per hex

Shown subtly on hover

Never explained in full

UI use:

Tooltip subtitle

Small icon or color pulse

Player takeaway:
“This place wants this kind of interaction.”

2. Current State (why now matters)
export type HexState =
  | "Dormant"
  | "Stirring"
  | "Active"
  | "Fading"
  | "Sealed"
  | "Compromised";


This is what changes when:

A check fails

Time passes

Noise is made

Another hex escalates

Example:
A Whispering Chamber can move from Dormant → Stirring → Active.

3. Affordances (what play it supports)

These directly bias scene generation and choices.

export interface HexAffordances {
  exploration: number; // 0–5
  social: number;
  investigation: number;
  puzzle: number;
  combat: number;
}


Important:
Combat does not need to be zero.
It just shouldn’t be the default.

4. Escalation (how the hex pushes back)
export interface HexEscalation {
  trigger: "Failure" | "Delay" | "Noise" | "RepeatedUse";
  effect: HexEscalationEffect;
}

export type HexEscalationEffect =
  | "IncreaseTension"
  | "ChangeTone"
  | "SealAdjacentHex"
  | "SummonThreat"
  | "TransformIntoCombatScene";


This is how:

Exploration turns dangerous

Social mistakes ripple outward

Combat emerges organically

5. Knowledge Hooks (reward exploration)
export interface KnowledgeHook {
  id: string;
  category: "Lore" | "Warning" | "Leverage" | "MapInsight";
  description: string;
  consumedOnUse?: boolean;
}


These replace some XP rewards without removing XP.

Example:

“The spirits are bound to the eastern portal.”

“The dragon avoids consecrated ground.”
