# I. Everdice Threat Archetype Schema (Canonical v1.0)

This schema is not a stat block.
It is a **narrative–behavioral object** that wraps *any* system.

---

## 1. Archetype Header

```yaml
archetype_id: string
display_name: string
threat_tier: low | medium | high | apex
playstyle_role: brute | skirmisher | controller | support | solo | swarm
```

**Why this matters**

* `threat_tier` replaces CR anxiety
* `playstyle_role` helps the DM visualize combat flow immediately

---

## 2. Narrative Function (Most Important)

```yaml
narrative_function:
  purpose: string
  story_pressure: string
  when_to_use: string
```

**Example**

* purpose: “Forces confrontation through territorial dominance”
* story_pressure: “The longer it is ignored, the worse the situation becomes”
* when_to_use: “When players hesitate or split focus”

This tells the DM *why this exists*.

---

## 3. Behavioral Logic (How It Acts)

```yaml
behavior:
  default_tactic: string
  under_pressure: string
  when_winning: string
  when_losing: string
```

This is what lets an insecure DM answer:

> “What would it do *now*?”

No guessing. No scripts.

---

## 4. Escalation Clock (Training Wheels)

```yaml
escalation:
  trigger: string
  stages:
    - stage: 1
      description: string
    - stage: 2
      description: string
    - stage: 3
      description: string
```

This is the **anti-freeze mechanism**.
If the DM stalls, the world moves.

---

## 5. Consequence Hooks (DM Choice Menu)

```yaml
consequences:
  if_players_succeed:
    - string
  if_players_fail:
    - string
  if_players_delay:
    - string
  unexpected_player_action:
    - string
```

These are **prompts**, not mandates.

---

## 6. System Adapters (Optional Layer)

```yaml
system_adapters:
  dnd5e_stub:
    difficulty_band: easy | standard | deadly
    damage_profile: low | mixed | high
    save_pressure: physical | mental | mixed
```

No IP. No stat blocks.
Just enough to translate.

---

## 7. Reskin Suggestions (Critical for Creativity)

```yaml
reskins:
  - string
  - string
  - string
```

This prevents creative paralysis.

---

## 8. DM Confidence Note (Psychological Support)

```yaml
dm_note: string
```

This is explicitly reassuring and instructional.

## 1. The Territorial Brute

```yaml
display_name: Territorial Brute
threat_tier: low
playstyle_role: brute
```

**Narrative Function**

* purpose: Controls space through force
* story_pressure: Forces players to commit or retreat
* when_to_use: Early dungeons, roadblocks, guardians

**Behavior**

* default_tactic: Blocks movement and attacks nearest threat
* under_pressure: Becomes reckless
* when_winning: Presses advantage
* when_losing: Tries to smash an escape

**Escalation**

* trigger: Players linger
* stages:

  * Loud warnings
  * Reinforced defenses
  * Environmental damage

**Reskins**

* Ogre
* Stone guardian
* Mutated beast

**DM Note**

> “This creature exists to be obvious. Let it be simple.”

* Every threat answers “what happens next?”
* Escalation removes paralysis
* Reskins encourage creativity
* No IP exposure
* System-agnostic by design

This is *exactly* the layer Everdice should own.
