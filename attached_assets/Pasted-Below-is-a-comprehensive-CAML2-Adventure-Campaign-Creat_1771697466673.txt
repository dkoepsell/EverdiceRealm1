CAML2 ADVENTURE & CAMPAIGN CREATION SPEC
(For #verdice Autonomous Campaign Generation)
I. CORE DESIGN AXIOMS

Every autogenerated adventure must satisfy:

1. Agency Integrity

No outcome is pre-scripted.

The villain must be defeatable.

The party must be able to fail meaningfully.

Multiple structural outcomes must exist.

2. Escalation Curve

Each adventure must follow:

Hook

Rising complications

Midpoint revelation or twist

Escalation

Climax

Aftermath (open threads allowed)

3. Reaction Modeling

Villains react to player interference.
Use conditional branches, not linear chains.

4. Objective Clarity

Every encounter must answer:

What do the players need to accomplish?

What changes if they succeed?

What changes if they fail?

5. Resource Pressure

Campaign pacing must consider:

XP thresholds

Adventuring day budgets

Short rest distribution

Resource drain patterns

III. FRAMING EVENT ENGINE

Every adventure begins with a Framing Event.

This provides urgency and context.

CAML2 should randomly or procedurally generate from categories:

Political (coronation, council meeting, treaty signing)

Social (festival, wedding, tournament)

Celestial (eclipse, conjunction)

Criminal (execution, trial, uprising)

Natural (migration, comet, disaster)

Personal (birth, funeral, investiture)

Framing Event must:

Increase instability in at least one faction.

Create opportunity for villain action.

Create player visibility.

IV. VILLAIN MODEL (CAML2 REACTION TREE)

Villains must be generated using one of four structural models:

A. One-and-Done

Single high-impact event → flee or hide.

B. Serial Escalation

Repeated crimes, increasing stakes.

C. Step-by-Step Ritual

Structured sequence of actions required for goal.

D. Growing Corruption

Influence spreads across regions/factions.

Villain Reaction Tree Schema
if party_thwarts_step:
    villain chooses:
        escalate
        redirect
        retaliate
        accelerate timeline

Every thwarted action must generate:

Resource cost for villain

New complication

World consequence

VII. DIFFICULTY CALIBRATION SYSTEM

Use official XP math:

1. Calculate Party Thresholds

For each character:

Easy

Medium

Hard

Deadly

Sum to party threshold.

2. Calculate Monster XP

Sum base XP.

3. Apply Encounter Multipliers
Monsters	Multiplier
1	x1
2	x1.5
3–6	x2
7–10	x2.5
11–14	x3
15+	x4
4. Compare Adjusted XP to Party Threshold

Match to difficulty band.

VIII. ADVENTURING DAY PRESSURE

Use Adventuring Day XP:

Each level has daily XP budget.

Campaign pacing must ensure:

6–8 medium/hard equivalents per day

2 short rest windows

Resource drain before climax

Deadly encounters reduce total encounter count per day.

IX. MULTIPART ENCOUNTERS

If encounter occurs in waves:

Each wave treated as separate XP calculation

No short rest allowed between waves

If combined adjusted XP > 1/3 of daily budget → mark as high strain

X. COMPLICATION SYSTEM

Each adventure must include at least:

1 Moral Quandary

Types:

Ally

Friend

Honor

Rescue

Respect

Must force:

Value tradeoff

Relationship cost

2 Twist

Examples:

Rival group racing

Time limit

False information

Two incompatible goals

Secretly helping villain

Magical compulsion

3 Environmental Modifier

High ground

Hazards

Elevation shifts

Restricted movement

XI. RANDOM ENCOUNTER ARCHITECTURE

Random encounters must never be filler.

They must serve one of:

Create urgency

Drain resources

Reinforce theme

Foreshadow villain

Provide assistance

Reveal lore

Random encounter trigger conditions:

Party resting

Party off track

Long journey

Drawing attention

Probability curve should weight middle results.

XII. SIDE QUEST STRUCTURE

Side quests must:

Be location-tied

Offer mechanical or narrative reward

Affect main arc

Side quest categories:

Rescue

Retrieve

Investigate

Hunt

Secure alliance

XIII. COMBAT INTEREST MODIFIERS

Combat must include at least one:

Verticality

Hazard

Forced movement mechanic

Environmental timer

Secondary objective

Avoid static slugfests.

Shift at least one global variable

Introduce new complication

Resolve at least one thread

Escalate or redirect central tension

XV. SESSION STRUCTURE FOR #VERDICE

Each session:

Hook scene (immediate engagement)

Objective clarity

Complication introduced early

Midpoint shift or revelation

Villain reaction event

Climax encounter

Aftermath consequences

Forward-facing hook

Never end on flat resolution.

XVI. FAILURE POLICY

Failure must:

Change faction alignment

Advance villain plan

Increase corruption scale

Reduce resources

Trigger escalation

Failure is not “try again.”
Failure advances world state.

XVII. PERSISTENT STATE TRACKING

CAML2 must persist:

NPC relationship levels

Faction standing

Unresolved moral debts

Promises made

Prophecies triggered

Timelines advancing

Villains continue acting offscreen.

XVIII. DESIGN ANTI-PATTERNS (DO NOT GENERATE)

Single-path resolution

Combat without objective

Random encounter with no narrative purpose

Villain who cannot be stopped

Infinite exposition

No consequences for player choice

XIX. QUALITY CHECKLIST FOR AUTO-GENERATED ADVENTURES

Before finalizing:

Does the villain react?

Does the party have meaningful choice?

Does at least one encounter strain resources?

Is there at least one moral tension?

Does the climax hinge on player decisions?

Does the world shift afterward?

If any answer is no → regenerate or patch.
