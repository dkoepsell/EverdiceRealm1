III. Upgraded CAML2 Architecture for Murmurs of War
A. Add Villain Plan Structure

Sylara must not be “final boss.”

She must have a staged plan.

Add:

"villain": {
  "id": "VIL_Sylara",
  "archetype": "Step-Based Conspiracy",
  "goal": "Expose or weaponize the castle's buried secrets to destabilize Eldric's rule.",
  "plan_stages": [
    {
      "id": "Stage1_GatherIntel",
      "trigger": "adventure_start",
      "effect": "increase stake_secrets by 1 over time"
    },
    {
      "id": "Stage2_ManipulateGuard",
      "trigger": "if stake_stability >= 3",
      "effect": "Captain Roth suspicion rises"
    },
    {
      "id": "Stage3_OpenHiddenChamber",
      "trigger": "if HiddenChamber_Discovered == true",
      "effect": "ritual destabilizes castle wards"
    },
    {
      "id": "Stage4_PublicReveal",
      "trigger": "if stake_secrets >= 4",
      "effect": "civil unrest erupts"
    }
  ]
}

Now the villain acts without player permission.

B. Add Reaction Tree

When players interfere:

"reaction_tree": [
  {
    "if": "players ally with Maelis",
    "then": "Sylara accelerates Stage2"
  },
  {
    "if": "players fail to stabilize guard",
    "then": "stake_stability +1"
  },
  {
    "if": "players expose Sylara early",
    "then": "Sylara flees and shifts to guerrilla mode"
  }
]

Now the system becomes reactive.

C. Convert Processes to Conditional Activation

For level 3 party example:

Medium threshold per character: 150
4 PCs → 600 medium XP

Hard threshold: 900

Daily budget (level 3): 1200 per PC → 4800 adjusted XP/day

Now enforce:

Add to file:

"encounter_budget": {
  "party_level": 3,
  "medium_threshold": 600,
  "hard_threshold": 900,
  "daily_budget": 4800,
  "target_strain_ratio": 0.7
